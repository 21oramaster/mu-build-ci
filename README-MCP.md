# MuMainMCP
Private copy of sven-n/MuMain used to build a client with the control socket
(`ENABLE_CONTROL_SOCKET=ON`) and editor for the MuMainMCP MCP.
Dev/test only: do not distribute this build to players.
Workflow: `.github/workflows/build-control-socket.yml` (Windows x64, artifact `MuMainMCP-windows-x64-control-socket`).
